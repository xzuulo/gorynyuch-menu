💻 Описание проекта: "Интерактивная галерея изображений" 🎨

Проект представляет собой веб-приложение, которое позволяет пользователям просматривать и взаимодействовать с изображениями в удобном и привлекательном интерфейсе. Галерея включает в себя множество функций и стилей, которые делают её уникальной и интересной.

🛠️ **Технологии**
- HTML5: Используется для структурирования содержания страницы. - CSS3: Применяется для стилизации элементов и создания адаптивного дизайна. - JavaScript: Добавляет интерактивность и управляет поведением интерфейса.
🎯 **Функционал**
1. **Модальное окно**: При клике на изображение открывается модальное окно с увеличенной версией изображения. 2. **Слайдер**: Пользователи могут прокручивать изображения в галерее с помощью стрелок или с помощью перетаскивания. 3. **Фильтры**: Возможность фильтровать изображения по категориям (например, природа, архитектура, люди). 4. **Адаптивный дизайн**: Галерея хорошо отображается на всех типах устройств, включая мобильные телефоны и планшеты.
📁 **Структура проекта**
``` /galery-project ├── index.html ├── styles.css ├── script.js └── images/ ├── img1.jpg ├── img2.jpg └── img3.jpg ```
🚀 **Как запустить проект**
1. Скачайте или клонируйте репозиторий на свой компьютер. 2. Откройте файл `index.html` в любом веб-браузере. 3. Наслаждайтесь просмотром изображений! 📷
